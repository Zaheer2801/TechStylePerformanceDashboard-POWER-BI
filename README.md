# TechStyle Performance Dashboard - Power BI

## Project Overview
The TechStyle Performance Dashboard is an interactive Power BI project designed to help retail leadership analyze overall business performance through sales, profit, customer, product, regional, and time-based insights.

This dashboard was developed as part of an advanced business intelligence assignment focused on executive storytelling, interactivity, and DAX-based performance analysis. The project transforms raw retail transaction data into a structured, professional dashboard that supports better strategic decision-making.

## Key Features
- Three-page interactive dashboard design
- KPI cards for executive-level monitoring
- Time intelligence measures using DAX
- YoY, YTD, PYTD, and MTD calculations
- Interactive slicers with sync across pages
- Drill-through page for product details
- Conditional formatting for performance monitoring
- Custom tooltips and bookmarks
- Professional executive-style dashboard layout

## DAX Measures Used
The project includes several important DAX measures, such as:
- Total Sales
- Total Profit
- Total Units
- Total Orders
- Avg Order Value
- Profit Margin %
- Sales PY
- Sales YoY %
- Sales YTD
- Sales PYTD
- Sales MTD
- Performance
- Product Rank
- Segment % of Total
